概要

車両の詳細ページです（URL: /vehicles/$vehicleId。親の レイアウトルートと同じ URL に .index の子ルートとして重なります）。 車両区分・車検満了日・備考の表示、編集ページへのリンク、削除ボタンを持ちます。

コード解説

const { vehicle } = Route.useRouteContext()

親のレイアウトルート（_authed.vehicles.$vehicleId.tsx）の beforeLoad が積んだ vehicle を受け取ります。 自分で getVehicleFn を呼び直す必要はありません。 _authed.index.tsx が user を受け取るのと同じ仕組みです。 

async function handleDelete() {
  const confirmed = window.confirm(`「${vehicle.name}」を削除します。整備記録も全て削除されます。よろしいですか？`)
  if (!confirmed) {
    return
  }
  setDeleting(true)
  try {
    await deleteVehicleFn({ data: { id: vehicle.id } })
    await navigate({ to: '/vehicles' })
  } finally {
    setDeleting(false)
  }
}

削除は取り消せない操作（かつ整備記録も一緒に消える）なので、 window.confirm でのワンクッションを必ず挟みます。 キャンセルされたら何もせずに戻り、確認が取れた場合のみ deleteVehicleFn を呼んで一覧ページへ遷移します。 

<p>
  車検満了日:{' '}
  {vehicle.shaken_expiry_date ? formatJa(toDateString(vehicle.shaken_expiry_date)) : '車検対象外'}
</p>

DB の shaken_expiry_date は null 許容の生の string です。null（250cc以下のバイク等）なら 「車検対象外」と表示し、値があれば toDateString で ブランド型 DateString へ検証してから formatJa （date-fns を使う表示専用の関数）で日本語表記に整形します。 素の文字列を直接 new Date() に渡さないのが、このプロジェクトの JST/UTC のずれを防ぐ原則です。
