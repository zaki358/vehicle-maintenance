概要

整備記録の編集ページです （URL: /vehicles/$vehicleId/records/$recordId/edit）。 対象の記録を loader で特定し、見つからなければ _authed.vehicles.$vehicleId.tsx（車両詳細）と同じ考え方で notFound() を返します。

実装プランに列挙されたサーバー関数は list/create/update/delete/ list-part-details の5本で、記録1件だけを取得する専用関数 （get.ts 相当）は含まれていません。このページは代わりに 車両スコープの一覧（listRecordsFn）を取得し、 対象IDをこのファイル内で絞り込みます。

構成

名前種別説明
Routeconst（export）編集ページのルート定義。対象記録が見つからなければ notFound()
RecordNotFoundfunction（component）記録が見つからない場合の専用画面

コード解説

loader: async ({ params }) => {
  const [records, partDetails] = await Promise.all([
    listRecordsFn({ data: { vehicleId: params.vehicleId } }),
    listPartDetailsFn({ data: { vehicleId: params.vehicleId } }),
  ])
  const record = records.find((candidate) => candidate.id === params.recordId)
  if (!record) {
    throw notFound()
  }
  return { record, records, partDetails }
}

listRecordsFn は指定した vehicleId（かつRLSにより 自分の車両）の記録しか返さないため、「他の車両の記録ID」や 「他人の記録ID」を $recordId に直接指定してURLへ来ても、 一覧の中に見つからず自然に notFound() になります。 存在しないIDと閲覧権限がないIDを区別しないのは、車両詳細ページの _authed.vehicles.$vehicleId.tsx と同じ設計判断です。
