概要

車両一覧ページです。URL は /vehicles（ファイル名の .index は「親ルート自身のパスにマッチする」という TanStack Router の規約）。ログイン中ユーザーの車両を一覧表示し、 新規登録ページと各車両の詳細ページへのリンクを出します。

構成

名前種別説明
Routeconst（export）/vehicles ルートの定義
VehiclesIndexPagefunction（component）一覧の描画

コード解説

export const Route = createFileRoute('/_authed/vehicles/')({
  loader: () => listVehiclesFn(),
  component: VehiclesIndexPage,
})

loader でデータ取得を宣言しておくと、TanStack Router は ナビゲーション中（画面遷移のアニメーションやコード分割の読み込みと 並行して）にこれを実行します。コンポーネントが実際に描画される時点では listVehiclesFn() がすでに完了しているため、 「ローディング中はスピナーを出して、終わったら描画する」という よくある2段階の書き方をせずに済みます。 

const vehicles = Route.useLoaderData()

loader が返した値を型安全に取り出します。戻り値の型は listVehiclesFn（延いては listVehiclesHandler）から 自動的に推論されます。 

<Link to="/vehicles/$vehicleId" params={{ vehicleId: vehicle.id }}>
  {vehicle.name}（{vehicleTypeLabel(vehicle.vehicle_type as VehicleType)}）
</Link>

vehicle.vehicle_type は DB の行の型では単なる string（Supabase の型生成はテーブルの CHECK 制約までは 読み取らない）なので、VehicleType（'car' | 'motorcycle'）へ キャストしています。これは外部から届いた値ではなく、自分たちが書いた CHECK 制約付きの自テーブルからの読み取りであるため許容しています。
