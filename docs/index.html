アプリの概要

車・バイクを複数台登録し、車検満了日と整備記録（オイル交換・タイヤ交換など）を個人ごとに記録・閲覧できる モバイルファーストの Web アプリです。招待制（公開サインアップ無効）のメール＋パスワード認証で、 利用者が自分のデータしか見られないことを Supabase の Row Level Security（RLS）で保証しています。 車検の満了が近づくとアプリ内（ダッシュボード・車両詳細）で警告を表示しますが、メール／Push／LINE 通知や定期実行（Cron）は意図的に持たない、閲覧時に計算するだけのシンプルな設計です。

主な機能

  • 認証 — メール＋パスワードログイン。公開サインアップは無効で、オーナーが scripts/invite-user.ts で招待し、招待された側が /set-password で初期パスワードを設定する
  • 車両管理 — 車種名・車両区分（車／バイク）・車検満了日（任意。250cc 以下のバイク等は 車検なしを想定）を登録・編集・削除
  • 整備記録 — 日付・作業内容（プリセット7種＋自由入力）・走行距離・部品／型式・備考を 車両ごとに記録。作業内容フィルタ、部品/型式の過去入力サジェスト、走行距離の逆行（前後の記録と矛盾する値）警告つき
  • 車検アラート — 満了までの残り日数を暦月単位で判定し、 「残り2ヶ月→警告」「残り1ヶ月→危険」「超過→期限切れ」の3段階をダッシュボード・車両詳細に表示
  • 車検更新の記録 — 受検日と有効期間（+2年／+3年）から次の満了日を制度どおり 自動計算（満了日の1ヶ月前以内に受検した場合は「旧満了日＋N年」に繰り越し）。計算結果は手動修正も可能で、 記録の追加と満了日の更新を1つのDBトランザクション（complete_shaken RPC）で行う
  • ダッシュボード — 登録車両ごとに現在の走行距離・前回整備日・車検アラートを一覧表示

設計上の要点

  • JST と UTC — Cloudflare Workers の実行環境は常に TZ=UTC だが利用者は JST。 カレンダー計算に生の Date を使わず、todayInJst() と branded 型 DateString で 「JST の暦日」だけを扱う。表示整形（date-fns）は UTC ゲッターで実装し、環境依存を避けている
  • Supabase クライアントのメモ化禁止 — サーバー用クライアントをモジュールスコープでメモ化すると、 Workers の isolate 再利用で他人のセッションを掴む危険があるため、リクエストのたびに生成する
  • RLS の UPDATE ポリシー — USING と WITH CHECK の両方を書き、 所有権の書き換え（他人の user_id への付け替え）を防ぐ
  • 境界のある純粋関数 — src/**/lib/** は ESLint ルールで React/TanStack/Supabase の import を禁止。テスト容易性とロジックの独立性を保証する
  • 全書き込みはサーバー側で Zod 検証 — サーバー関数は実 HTTP エンドポイントのため、 クライアント側の入力チェックを信用しない
